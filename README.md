## 📂 Proyectos

### * Leadership Workshop Analytics Dashboard
  
• Excel and VBA Automation Project that combines pivot tables, interactive charts, and macros to consolidate registration, attendance, and revenue data. The system enables automated report generation, dynamic visualization, and time optimization for event management.

• Proyecto de Automatización en Excel y VBA que integra tablas dinámicas, gráficos interactivos y macros para consolidar datos de registros, asistencia e ingresos. El sistema permite generación automática de reportes, visualización dinámica y optimización del tiempo en la gestión de eventos.
